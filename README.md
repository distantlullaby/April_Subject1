# Obsidian Link Fixer 插件

## 功能说明

本插件解决了Obsidian中复制粘贴内容时内部链接路径不正确的问题：

**问题场景：**
- 文件B中有标题1
- 文件A中引用了文件B的标题1
- 将文件A中包含该引用的内容复制/剪切到文件C中
- **问题**：文件C中的链接路径仍然基于文件A的相对路径，导致链接无法正确跳转

**解决方案：**
本插件会自动监听粘贴事件，检测粘贴内容中的内部链接，并根据目标文件的位置自动更新为正确的相对路径。

## 安装方法

1. 在你的Obsidian仓库的 `.obsidian/plugins/` 目录下创建 `obsidian-link-fixer` 文件夹
2. 将以下三个文件复制到该文件夹中：
   - `main.js`（编译后的文件）
   - `manifest.json`
   - `styles.css`
3. 在Obsidian设置中启用"Link Fixer"插件

## 编译方法

```bash
npm install
npx tsc
```

## 使用方法

### 自动修复（推荐）
正常复制粘贴内容即可，插件会自动检测并修复链接路径

### 手动修复
选中需要修复的内容，使用命令面板执行 **"Link Fixer: 修复选区内的链接路径"**

## 支持的链接格式

- 标准Wiki链接：`[[文件名]]`
- 带锚点的链接：`[[文件名#标题]]`
- 带显示文本的链接：`[[文件名|显示文本]]`
- 带锚点和显示文本的链接：`[[文件名#标题|显示文本]]`
